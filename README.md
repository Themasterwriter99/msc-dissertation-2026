# msc-dissertation-2026
Dataset and other files relating to the BUSI1783 Business Analytics Project
The project was conducted relating to the stratagies that can be used the enhance to quality of online food delivery services in India. Zomato was taken as the main example for the project
The data set comprises of 205 responses gathered from users of Zomato by sharing a questionaire
SSPS was used as the main analytical tool to analyze the data gathered
The SSPS input file and the SSPS output file are also included in the repository
